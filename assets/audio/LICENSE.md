# Audio assets

- `tick.ogg` — Kenney "Interface Sounds", source file `click_002.wav`, converted to OGG Vorbis.
- `accent.ogg` — Kenney "Interface Sounds", source file `click_004.wav`, converted to OGG Vorbis.

Source pack: https://kenney.nl/assets/interface-sounds
Mirror used for download: https://github.com/Calinou/kenney-interface-sounds
License: Creative Commons Zero (CC0 1.0), original license text follows.

- `candidates/` — audition bank for the in-app sample selector. All Freesound
  entries are license "Creative Commons 0"; each file is a processed
  high-quality CDN preview (mono 44.1 kHz Vorbis q5, silence-trimmed,
  peak-normalized, accent = 1.25x pitch-up). Per-file sources, titles and
  authors are listed in `candidates/MANIFEST.md`. Generated `gen_*` clicks are
  synthesized by `scripts/build_candidate_bank.py` (no external license).
  Before promoting a kept sample to a permanent preset, re-export it from the
  original Freesound file.
