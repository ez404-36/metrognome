## จุดเด่น

- 🎯 **การจัดตารางด้วยนาฬิกาตัวอย่าง** — เคาะจังหวะถูกวางแผนเป็นตัวอย่างเสียง และใช้สตรีมเอาต์พุต `cpal` อย่างต่อเนื่อง
- 🎚 **20–300 BPM** — ปรับความเร็วอย่างต่อเนื่องและ tap tempo โดยไม่หลุดจังหวะ
- 🥁 **จุดเน้นที่คลิกได้** — รอบ 2/4, 3/4, 4/4 และ 6/8 คลิกจังหวะเพื่อปรับจุดเน้น
- 🔊 **เสียงในตัว** — พรีเซ็ต Classic, Woodblock, Digital และ Soft
- 🎛 **เสียงของคุณ** — นำเข้าไฟล์ WAV แบบ PCM 16 บิตหรือจุดทศนิยม Metrognomeจะ downmix, resample และ normalize ให้
- 🖤 **UI libadwaita** — คอนโทรล GNOME แบบเนทีฟ รองรับธีมสว่างและเข้ม
- 💾 **การตั้งค่าที่เชื่อถือได้** — บันทึกการตั้งค่าด้วยการเขียนไฟล์ชั่วคราวแบบอะตอมมิก

## เริ่มต้นอย่างรวดเร็ว

ติดตั้งแพ็กเกจพัฒนา GTK บน Debian หรือ Ubuntu:

```sh
./scripts/install-deps.sh
```

คอมไพล์และรัน UI เดสก์ท็อป:

```sh
cargo run --features ui
```

รันการทดสอบแกนเสียง:

```sh
cargo test
```

การทดสอบ smoke ผ่าน CLI มีประโยชน์เมื่อไม่มีเดสก์ท็อปเซสชัน:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

บน GNOME หรือ Wayland ให้เปิดแอปจากเดสก์ท็อปเซสชัน ไม่ใช่จากสภาพแวดล้อม SSH เท่านั้น

## วิธีทำงาน

GUI เปลี่ยนเฉพาะพารามิเตอร์และแสดงสถานะ audio callback เป็นผู้ครองนาฬิกาตัวอย่าง:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

วิธีนี้ช่วยลดการเลื่อนจังหวะและความผิดพลาดสะสม แม้ที่ความเร็วสูง
