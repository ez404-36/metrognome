## أبرز المزايا

- 🎯 **جدولة بساعة العينات** — تُخطَّط النبضات في عينات صوتية مع تدفق خرج `cpal` مستمر.
- 🎚 **20–300 نبضة في الدقيقة** — تغييرات متدرجة للإيقاع وإيقاع باللمس دون فقدان النبضة.
- 🥁 **تشديدات قابلة للنقر** — أنماط 2/4 و3/4 و4/4 و6/8؛ انقر نبضة لتخصيص التشديدات.
- 🔊 **أصوات مدمجة** — إعدادات Classic وWoodblock وDigital وSoft.
- 🎛 **أصواتك** — استورد ملفات WAV بنظام PCM ثنائي 16 بت أو فاصلة عائمة؛ ينفّذ Metrognome الخفض، وإعادة الاستعراء، والتطبيع.
- 🖤 **واجهة libadwaita** — عناصر GNOME أصلية تدعم المظهر الفاتح والداكن.
- 💾 **إعدادات موثوقة** — تُحفظ الإعدادات بكتابة ذرية في ملف مؤقت.

## بداية سريعة

ثبّت تبعيات تطوير GTK على Debian أو Ubuntu:

```sh
./scripts/install-deps.sh
```

ابنِ واجهة سطح المكتب وشغّلها:

```sh
cargo run --features ui
```

شغّل اختبارات نواة الصوت:

```sh
cargo test
```

اختبارات سطر الأوامر الدخانية مفيدة بدون جلسة سطح مكتب:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

على GNOME أو Wayland، شغّل التطبيق من جلسة سطح المكتب لا من بيئة SSH فقط.

## كيف يعمل

تغيّر الواجهة الرسومية المعاملات وتعرض الحالة فقط. يمتلك رد نداء الصوت ساعة العينات:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

وهذا يمنع الانحراف وخطأ الزمن المتراكم، حتى عند الإيقاعات السريعة.
