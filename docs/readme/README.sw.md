## Vipengele muhimu

- 🎯 **Upangaji kwa saa ya sampuli** — Vibrationo hupangwa kama sampuli za sauti kwa mtiririko endelevu wa `cpal`.
- 🎚 **20–300 BPM** — Mabadiliko endelevu ya tempo na tap tempo bila kupoteza rythmu.
- 🥁 **Misisitizo inayobofyeka** — Mifumo ya 2/4, 3/4, 4/4 na 6/8; bofya vibrationo kubadilisha msisitizo.
- 🔊 **Sauti zilizojengwa ndani** — Preset za Classic, Woodblock, Digital na Soft.
- 🎛 **Sauti zako** — Ingiza faili za WAV za PCM biti 16 au floating-point; Metrognome hufanya downmix, resample na normalization.
- 🖤 **UI ya libadwaita** — Vidhibiti vya asili vya GNOME vinavyounga mkono mandhari nyepesi na nyeusi.
- 💾 **Mipangilio ya kuaminika** — Mipangilio huhifadhiwa kwa uandishi atomik wa faili ya muda.

## Anza haraka

Sakisha mahitaji ya usanidi wa GTK kwenye Debian au Ubuntu:

```sh
./scripts/install-deps.sh
```

Jenga na uendeshe UI ya desktop:

```sh
cargo run --features ui
```

Endesha vipimo vya kiini cha sauti:

```sh
cargo test
```

Vipimo vya smoke vya CLI ni muhimu bila kikao cha desktop:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

Kwenye GNOME au Wayland, anzisha programu kutoka kikao cha desktop, sio kutoka mazingira ya SSH pekee.

## Inavyofanya kazi

GUI hubadilisha vigezo na kuonyesha hali tu. Callback ya sauti ina saa ya sampuli:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

Hii huondoa drift na kosa la muda linalojikusanya, hata kwenye tempo za juu.
