## ముఖ్య ఫీచర్లు

- 🎚 **20–300 BPM** — సజావైన టెంపో మార్పులు మరియు ట్యాప్ టెంపో.
- 🥁 **అనుకూలీకరించదగిన తాళాలు** — 2/4, 3/4, 4/4 మరియు 6/8 తాళాలకు మద్దతు ఉంది.
- 🎯 **బీట్‌లను మ్యూట్ చేయడం** — ఏదైనా బీట్ శబ్దాన్ని ఆపివేయవచ్చు.
- 🔊 **18 అంతర్భాగ నమూనాలు.**

## ప్రణాళికలో ఉన్నవి

## ఇది ఎలా పనిచేస్తుంది

GUI ప్యారామీటర్లను మాత్రమే మారుస్తుంది మరియు స్థితిని చూపుతుంది. బీట్‌ను నడిపే GUI టైమర్‌లు లేదా `sleep` కాల్‌లు లేవు — టైమింగ్ మొత్తం రియల్-టైమ్ ఆడియో కాల్‌బ్యాక్ (`cpal`) లోపల ఉంటుంది, అక్కడ తదుపరి హిట్ స్యాంపుల్‌లలో ఖచ్చితమైన స్థానంగా లెక్కించబడుతుంది, గోడ గడియారపు సెకన్లలో కాదు:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

దీని వల్ల ఎక్కువ టెంపోల వద్ద కూడా డ్రిఫ్ట్ మరియు పేరుకున్న సమయ లోపం తప్పుతుంది, మరియు టెంపో మార్పులకు పునఃప్రారంభం అవసరం లేదు: పెండింగ్ హిట్ దాని నిర్ణయించిన స్థానంలోనే ఉంటుంది, కొత్త వ్యవధి తదుపరి బీట్ నుండి వర్తిస్తుంది.
