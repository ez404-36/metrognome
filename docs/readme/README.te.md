## ముఖ్య ఫీచర్లు

- 🎯 **స్యాంపుల్-క్లాక్ షెడ్యూలింగ్** — నిరంతర `cpal` అవుట్‌పుట్ స్ట్రీమ్‌తో బీట్లు ఆడియో స్యాంపుల్స్‌లో ప్లాన్ చేయబడతాయి.
- 🎚 **20–300 BPM** — లయను కోల్పోకుండా నిరంతర టెంపో మార్పులు మరియు టాప్ టెంపో.
- 🥁 **క్లిక్ చేయదగిన యాక్సెంట్లు** — 2/4, 3/4, 4/4 మరియు 6/8 నమూనాలు; యాక్సెంట్ మార్చడానికి బీట్‌పై క్లిక్ చేయండి.
- 🔊 **అంతర్భాగ ధ్వనులు** — Classic, Woodblock, Digital మరియు Soft ప్రీసెట్‌లు.
- 🎛 **మీ ధ్వనులు** — 16-బిట్ PCM లేదా ఫ్లోటింగ్-పాయింట్ WAV దిగుమతి చేయండి; Metrognome డౌన్‌మిక్స్, రీస్యాంప్లింగ్, నార్మలైజేషన్ చేస్తుంది.
- 🖤 **libadwaita UI** — లైట్ మరియు డార్క్ థీమ్‌లకు తోడ్పాటుతో నేటివ GNOME కంట్రోల్స్.
- 💾 **నమ్మదగిన సెట్టింగ్‌లు** — టెంపరరీ ఫైల్‌లో అటామిక్ రైటింగ్ ద్వారా సెట్టింగ్‌లు సేవ్ అవుతాయి.

## త్వరగా ప్రారంభించడం

Debian లేదా Ubuntu లో GTK డెవలప్‌మెంట్ డిపెండెన్సీలను ఇన్‌స్టాల్ చేయండి:

```sh
./scripts/install-deps.sh
```

డెస్క్‌టాప్ UI బిల్డ్ చేసి రన్ చేయండి:

```sh
cargo run --features ui
```

ఆడియో కోర్ టెస్టులను రన్ చేయండి:

```sh
cargo test
```

డెస్క్‌టాప్ సెషన్ లేకుండా CLI స్మోక్ టెస్టులు ఉపయోగకరం:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

GNOME లేదా Wayland లో యాప్‌ను SSH మాత్రమే ఉన్న వాతావరణం నుంచి కాకుండా డెస్క్‌టాప్ సెషన్ నుంచి ప్రారంభించండి.

## ఇది ఎలా పనిచేస్తుంది

GUI ప్యారామీటర్లను మాత్రమే మారుస్తుంది మరియు స్థితిని చూపుతుంది. ఆడియో కాల్‌బ్యాక్ స్యాంపుల్ క్లాక్‌ను కలిగి ఉంటుంది:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

దీని వల్ల ఎక్కువ టెంపోల వద్ద కూడా డ్రిఫ్ట్ మరియు పేరుకున్న సమయ లోపం తప్పుతుంది.
