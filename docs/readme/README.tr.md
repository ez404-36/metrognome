## Öne çıkanlar

- 🎚 **20–300 BPM** — Akıcı tempo değişimi ve tap tempo.
- 🥁 **Özelleştirilebilir ölçüler** — 2/4, 3/4, 4/4 ve 6/8 ölçüleri desteklenir.
- 🎯 **Vuruşları susturma** — Herhangi bir vuruşun sesi kapatılabilir.
- 🔊 **19 yerleşik örnek.**

## Planlanan
- 🎛 **Kendi sesleriniz** — 16 bit PCM ya da kayan nokta WAV dosyaları içe aktarın; Metrognome indirmix, yeniden örnekleme ve normalleştirme yapar.

## Hızlı başlangıç

Debian ya da Ubuntu üzerinde GTK geliştirme bağımlılıklarını kurun:

```sh
./scripts/install-deps.sh
```

Masaüstü arayüzünü derleyin ve çalıştırın:

```sh
cargo run --features ui
```

Ses çekirdeği testlerini çalıştırın:

```sh
cargo test
```

CLI duman testleri masaüstü oturumu olmadan kullanışlıdır:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

GNOME ya da Wayland’da uygulamayı yalnız SSH ortamından değil masaüstü oturumundan başlatın.

## Nasıl çalışır

GUI yalnızca parametreleri değiştirir ve durumu gösterir. Ses geri çağırımı örnek saatine sahiptir:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

Bu, yüksek temposlarda bile sürüklenmeyi ve birikmiş zaman hatasını önler.
