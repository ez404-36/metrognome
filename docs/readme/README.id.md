## Sorotan

- 🎚 **20–300 BPM** — Perubahan tempo halus dan tap tempo.
- 🥁 **Ukuran birama yang dapat disesuaikan** — Mendukung ukuran 2/4, 3/4, 4/4, dan 6/8.
- 🎯 **Bisukan ketukan** — Dapat mematikan suara pada ketukan mana pun.
- 🔊 **19 sampel bawaan.**

## Direncanakan
- 🎛 **Suara Anda** — Impor berkas WAV PCM 16-bit atau floating-point; Metrognome melakukan downmix, resampling, dan normalisasi.

## Mulai cepat

Instal dependensi pengembangan GTK di Debian atau Ubuntu:

```sh
./scripts/install-deps.sh
```

Bangun dan jalankan antarmuka desktop:

```sh
cargo run --features ui
```

Jalankan tes inti audio:

```sh
cargo test
```

Uji smoke CLI berguna tanpa sesi desktop:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

Di GNOME atau Wayland, jalankan aplikasi dari sesi desktop, bukan dari lingkungan SSH saja.

## Cara kerja

GUI hanya mengubah parameter dan menampilkan status. Callback audio memiliki jam sampel:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

Ini mencegah drift dan kesalahan waktu yang menumpuk, termasuk pada tempo tinggi.
