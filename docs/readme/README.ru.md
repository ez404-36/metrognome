## Основные возможности

- 🎚 **20–300 BPM** — Плавное изменение темпа и tap tempo.
- 🥁 **Настраиваемая размерность** — Поддерживаются размеры 2/4, 3/4, 4/4 и 6/8.
- 🎯 **Выключение долей** — Возможность выключения звука на любой из долей.
- 🔊 **Встроенные звуки** — 19 встроенных сэмплов.

## Планируется
- 🎛 **Свои звуки** — Импорт WAV в 16-битном PCM или с плавающей точкой; Takto выполняет даунмикс, ресемплинг и нормализацию.

Flatpak-бандл самодостаточен: GTK 4, libadwaita и ALSA входят в его рантайм,
поэтому он работает в любом дистрибутиве, где установлен `flatpak`, — системе
нужен только звуковой сервер (PipeWire или PulseAudio) и дисплей (Wayland или
X11). Установка:

```sh
flatpak install --user ./takto_<версия>_x86_64.flatpak
```

Инструкции по разработке и сборке находятся в [DEVELOP.md](../../DEVELOP.md). Все релизы доступны на [GitHub Releases](https://github.com/ez404-36/takto/releases/latest).

## Как это работает

GUI только меняет параметры и показывает состояние. Аудиокалбэк управляет сэмпловыми часами:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

Это исключает дрейф и накопленную ошибку времени, в том числе на высоких темпах.
