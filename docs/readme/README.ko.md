## 주요 기능

- 🎚 **20–300 BPM** — 부드러운 템포 변경 및 탭 템포.
- 🥁 **조절 가능한 박자** — 2/4, 3/4, 4/4, 6/8 박자 지원.
- 🎯 **비트 음소거** — 원하는 비트의 소리를 끌 수 있습니다.
- 🔊 **내장 샘플 19개.**

## 계획됨
- 🎛 **내 사운드** — 16비트 PCM 또는 부동소수점 WAV를 가져올 수 있으며, 다운믹스·리샘플링·정규화를 처리합니다.

## 작동 방식

GUI는 매개변수 변경과 상태 표시만 합니다. 오디오 콜백이 샘플 클록을 소유합니다:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

이를 통해 빠른 템포에서도 드리프트와 누적 시간 오류를 피할 수 있습니다.
