## 주요 기능

- 🎯 **샘플 클록 스케줄링** — 연속적인 `cpal` 출력 스트림에서 박자를 오디오 샘플 단위로 계획합니다.
- 🎚 **20–300 BPM** — 박자를 잃지 않고 연속적인 템포 변경과 탭 템포를 지원합니다.
- 🥁 **클릭 가능한 악센트** — 2/4, 3/4, 4/4, 6/8 패턴을 제공하며, 박자를 클릭해 악센트를 바꿀 수 있습니다.
- 🔊 **내장 사운드** — Classic, Woodblock, Digital, Soft 프리셋이 포함됩니다.
- 🎛 **내 사운드** — 16비트 PCM 또는 부동소수점 WAV를 가져올 수 있으며, 다운믹스·리샘플링·정규화를 처리합니다.
- 🖤 **libadwaita UI** — 라이트 및 다크 테마를 지원하는 네이티브 GNOME 컨트롤.
- 💾 **신뢰할 수 있는 설정** — 임시 파일에 원자적으로 기록해 설정을 저장합니다.

## 빠른 시작

Debian 또는 Ubuntu에서 GTK 개발 의존성을 설치하세요:

```sh
./scripts/install-deps.sh
```

데스크톱 UI를 빌드하고 실행합니다:

```sh
cargo run --features ui
```

오디오 코어 테스트를 실행합니다:

```sh
cargo test
```

데스크톱 세션이 없을 때는 CLI 스모크 테스트가 유용합니다:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

GNOME 또는 Wayland에서는 SSH 전용 환경이 아니라 데스크톱 세션에서 앱을 실행하세요.

## 작동 방식

GUI는 매개변수 변경과 상태 표시만 합니다. 오디오 콜백이 샘플 클록을 소유합니다:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

이를 통해 빠른 템포에서도 드리프트와 누적 시간 오류를 피할 수 있습니다.
