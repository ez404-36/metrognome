## मुख्य विशेषताएँ

- 🎚 **20–300 BPM** — सहज टेम्पो बदलाव और टैप टेम्पो।
- 🥁 **अनुकूलन योग्य ताल** — 2/4, 3/4, 4/4 और 6/8 ताल समर्थित हैं।
- 🎯 **बीट म्यूट करना** — किसी भी बीट की ध्वनि बंद करने की सुविधा।
- 🔊 **19 इनबिल्ट सैंपल।**

## नियोजित
- 🎛 **अपनी ध्वनियाँ** — 16-बिट PCM या फ़्लोटिंग-पॉइंट WAV आयात करें; Metrognome डाउनमिक्स, रीसैंपलिंग और नॉर्मलाइज़ेशन करता है।

## तेज़ शुरुआत

Debian या Ubuntu पर GTK विकास निर्भरताएँ इंस्टॉल करें:

```sh
./scripts/install-deps.sh
```

डेस्कटॉप UI बनाकर चलाएँ:

```sh
cargo run --features ui
```

ऑडियो कोर टेस्ट चलाएँ:

```sh
cargo test
```

डेस्कटॉप सत्र के बिना CLI स्मोक टेस्ट उपयोगी हैं:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

GNOME या Wayland पर ऐप को केवल SSH वातावरण से नहीं, बल्कि डेस्कटॉप सत्र से चलाएँ।

## यह कैसे काम करता है

GUI केवल पैरामीटर बदलता है और स्थिति दिखाता है। ऑडियो कॉलबैक सैंपल क्लॉक का स्वामी होता है:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

इससे तेज़ टेम्पो में भी ड्रिफ़्ट और संचित समय त्रुटि से बचा जाता है।
