## اہم خصوصیات

- 🎯 **سیمپل کلاک شیڈولنگ** — مسلسل `cpal` آؤٹ پُٹ اسٹریم کے ساتھ بیٹس آڈیو سیمپلز میں طے کیے جاتے ہیں۔
- 🎚 **20–300 BPM** — تال کھوئے بغیر مسلسل ٹیمپو تبدیلی اور ٹیپ ٹیمپو۔
- 🥁 **کلک کے قابل ایکسنٹ** — 2/4، 3/4، 4/4 اور 6/8 پیٹرن؛ ایکسنٹ بدلنے کے لیے کسی بیٹ پر کلک کریں۔
- 🔊 **بلٹ اِن آوازیں** — Classic، Woodblock، Digital اور Soft پری سیٹ۔
- 🎛 **آپ کی آوازیں** — 16 بٹ PCM یا فلوٹنگ پوائنٹ WAV درآمد کریں؛ Metrognome ڈاؤن مکس، ریسیمپلنگ اور نارملائزیشن کرتا ہے۔
- 🖤 **libadwaita انٹرفیس** — لائٹ اور ڈارک تھیم سپورٹ کے ساتھ مقامی GNOME کنٹرولز۔
- 💾 **قابلِ اعتماد ترتیبات** — ترتیبات عارضی فائل میں ایٹمک رائٹنگ سے محفوظ ہوتی ہیں۔

## تیز آغاز

Debian یا Ubuntu پر GTK ڈیولپمنٹ ڈیپینڈنسیاں انسٹال کریں:

```sh
./scripts/install-deps.sh
```

ڈیسک ٹاپ UI بنائیں اور چلائیں:

```sh
cargo run --features ui
```

آڈیو کور ٹیسٹ چلائیں:

```sh
cargo test
```

ڈیسک ٹاپ سیشن کے بغیر CLI سموک ٹیسٹ مفید ہیں:

```sh
cargo run -- --preset woodblock
cargo run -- --normal ./normal.wav --accent ./accent.wav
```

GNOME یا Wayland پر ایپ کو صرف SSH ماحول سے نہیں، ڈیسک ٹاپ سیشن سے چلائیں۔

## یہ کیسے کام کرتا ہے

GUI صرف پیرامیٹر بدلتا ہے اور حالت دکھاتا ہے۔ آڈیو کال بیک سیمپل کلاک کا مالک ہوتا ہے:

```text
GTK UI
  → BPM, pattern, volume, sound
  → audio engine

Audio callback
  → exact next-hit position in samples
  → mixes the click into the output buffer
  → publishes beat events to the UI
```

اس سے بلند ٹیمپو پر بھی ڈرفٹ اور جمع ہونے والی وقت کی غلطی سے بچا جاتا ہے۔
